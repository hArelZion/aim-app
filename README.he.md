# AIM: AI Manager

**סוכני ה-AI שלך, בכיס.** AIM היא אפליקציה פרטית לטלפון בשביל סוכני ה-AI שעובדים במחשב שלך: Claude Code, ChatGPT (Codex) ו-Gemini. נותנים משימה, הולכים, ועוקבים מהטלפון: רואים כל צעד בזמן אמת, עונים על שאלות, מאשרים הרשאות, שולחים תמונות וקבצים, ומקבלים התראה כשזה מוכן.

[English](README.md)

## מה מקבלים
- **Claude, ChatGPT ו-Gemini** באפליקציה אחת, ועוד **שיחת צוות** שבה Claude מוביל ומחלק עבודה לאחרים.
- **צעדים חיים**, כמו באפליקציות הרשמיות: פקודות, עריכות קבצים עם diff אמיתי, והצעד שרץ עכשיו עם טיימר.
- **הרשאות מהטלפון:** לאשר או לדחות את מה ש-Claude Code מבקש, בלי לחזור למחשב.
- **בחירת מודל, רמת מאמץ ומצב עבודה**, וגם המודל, רמת החשיבה וההרשאות של ChatGPT.
- **התראות** כשמשימה מסתיימת או צריכה אותך, גם כשהטלפון נעול.
- **תמונות וקבצים** לשני הכיוונים, הקלטה קולית, הקראה, תשובות מהירות, חיפוש, מצב כהה ובהיר.
- **קיצור דרך ל-Siri** לשאלות קוליות מהירות (אופציונלי).
- **37 שפות**, נבחרות אוטומטית לפי הטלפון (ברירת מחדל: אנגלית).

## איך זה עובד
```
 הטלפון (דף ה-AIM שלך)  <-->  פרויקט ה-Supabase שלך  <-->  המחשב שלך (הסקריפטים ב-aim./~)
                                                              -> Claude Code, Codex, Gemini
```
הכול שלך: ה-fork שלך מארח את הדף ב-GitHub Pages, פרויקט Supabase החינמי שלך שומר את השיחות, והמחשב שלך מריץ את הסוכנים עם החשבונות **שלך** ב-Claude, ב-ChatGPT וב-Gemini. אף סיסמה ואף מפתח לא עוברים דרך הדף או דרך מישהו אחר. כל טבלה נעולה למייל שלך בכללי הרשאה (RLS).

## מה צריך
- **Windows 10 או 11** (Mac ו-Linux בתכנון).
- [Python 3.10 ומעלה](https://www.python.org/downloads/), [Git for Windows](https://git-scm.com/download/win), [Claude Code](https://claude.com/claude-code).
- אופציונלי: [Codex CLI](https://github.com/openai/codex) (`npm i -g @openai/codex` ואז `codex login`) בשביל ChatGPT, ו[מפתח Gemini חינמי](https://aistudio.google.com/apikey) בשביל Gemini.
- חשבון [Supabase](https://supabase.com) חינמי וחשבון GitHub.

## התקנה (בערך 15 דקות)
1. **עושים fork** ל-repo הזה. ב-fork שלך: Settings ← Pages ← Deploy from a branch ← `main` / root. הדף שלך יהיה `https://<you>.github.io/<repo>/`.
2. **פותחים פרויקט Supabase** (חינם; בתוכנית החינמית מותר עד 2 פרויקטים פעילים לכל חשבון, אז אם מבקשים לשלם, משהים פרויקט ישן או נרשמים עם מייל אחר), ומשאירים פתוח את הדף Project Settings ← API Keys. אחר כך ב-Authentication ← URL Configuration שמים ב-**Site URL** את כתובת הדף משלב 1 ושומרים (אחרת קישור האישור במייל מוביל ל-`localhost`).
3. **מורידים את ה-fork למחשב** ומריצים את המתקין:
   ```
   git clone https://github.com/<you>/<repo>.git
   cd <repo>
   python install.py
   ```
   המתקין:
   - בודק את המחשב.
   - מבקש את פרטי Supabase. בכתובת הפרויקט אפשר להדביק את כתובת הדשבורד מהדפדפן; את המפתחות מעתיקים בכפתורי ההעתקה; המפתח הסודי מוקלד בהסתרה.
   - מעתיק את סקריפט מסד הנתונים ללוח ופותח את עורך ה-SQL של Supabase. שם מדביקים ולוחצים Run.
   - מתקין הכול ומציג **קוד QR**.
4. **בטלפון:** סורקים את ה-QR, לוחצים *פעם ראשונה*, יוצרים חשבון עם אותו מייל, מאשרים אותו, נכנסים ומוסיפים למסך הבית.
5. **נועלים:** ב-Supabase: Authentication ← Sign In / Providers ← מכבים את *Allow new users to sign up*.
6. ב-Claude Code מקלידים **`/phone`**, והקו פועל.

משהו לא עובד? מריצים **`python ~/.aim/aim.py doctor`**. הפקודה בודקת כל חלק ואומרת איך לתקן את מה שחסר.

## להפוך את זה לשלך
זה העותק שלך, ומותר לשנות בו הכול. הדף הוא קובץ אחד (`index.html`), וצד המחשב הוא Python פשוט בתיקייה `pc/`. לתצוגה מקדימה עם נתוני דוגמה ובלי חשבון: `python preview/preview.py` ואז פותחים http://localhost:8791. כדי להוסיף שפה: מעתיקים את `lang/de.json`, מתרגמים את הערכים ומוסיפים את הקוד ל-`LANGS` ב-`index.html`.

## אבטחה
- **המפתח הסודי** נשאר ב-`~/.aim/secrets.env` במחשב שלך. לא עושים לו commit ולא מדביקים אותו בצ'אט.
- כשהקו פועל, הודעות מהטלפון נחשבות כמו הודעות שהוקלדו ב-Claude Code. לכן **הכניסה שלך ל-Supabase היא מה ששומר על המחשב**: סיסמה חזקה, והרשמה של משתמשים חדשים כבויה.
- **שליטה במסך** (לראות את מסך המחשב ולהפעיל אותו מהטלפון) עובדת רק כשהקו פועל. במחשב מוצג פס אדום עם כפתור עצירה, והיא נגמרת אחרי 10 דקות. אפשר לדרוש PIN: `python ~/.aim/screen.py setpin`.
- ההודעות נשמרות בפרויקט ה-Supabase שלך (מוצפנות באחסון אצל Supabase, וניתנות לקריאה רק עם החשבון שלך).

## מגבלות
- כרגע Windows בלבד. החלפת מודל, מאמץ וסשן עובדת על ידי לחיצה על כפתורים באפליקציית Claude במחשב, ולכן היא **ניסיונית** ועלולה להישבר כשהאפליקציה מתעדכנת.
- פרויקט Supabase חינמי נרדם אחרי שבוע בלי פעילות. כדי להעיר אותו, פותחים אותו בלוח הבקרה של Supabase.
- האחריות לשימוש בחשבונות Claude, ChatGPT ו-Gemini לפי תנאי השימוש שלהם היא של כל משתמש.

## הסרה
מוחקים את `~/.aim`, את התיקיות `phone`, `phone-off` ו-`phone-new` ב-`~/.claude/skills` (וגם ב-`~/.codex/skills`), ואת ארבעת ה-hooks של `aim_tool.py` ב-`~/.claude/settings.json`. אחר כך אפשר למחוק את פרויקט ה-Supabase.
